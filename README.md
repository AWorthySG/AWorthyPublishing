# A-Worthy Publishing

Passcode-protected study pages for A-Worthy Education students.

- `amath/` — O-Level Additional Mathematics (4049) topical model solutions and teaching scripts. Content and images are encrypted; they open in the browser only with the passcode.

Built from the A-Worthy build scripts (`build.py`, `protect.py`). Do not edit `amath/` by hand; rebuild and replace it.
