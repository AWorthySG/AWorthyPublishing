# A-Worthy Publishing

Study pages for A-Worthy Education students.

- `amath/` — O-Level Additional Mathematics (4049) topical model solutions and teaching scripts (open access, hidden from search engines).
- `chemistry/` — O-Level Pure Chemistry (6092) Paper 2 practice by question type, 2020–2025, with answers (open access, hidden from search engines).
- `chem-mcq/` — O-Level Chemistry Paper 1 MCQ practice, 2020–2026, interactive with per-page marking (open access, hidden from search engines).

Built from the A-Worthy build scripts (`build.py`, `protect.py`). Chemistry is built by `web.py` in the 6092 Paper 2 analysis build. Do not edit `amath/` or `chemistry/` by hand; rebuild and replace it.
